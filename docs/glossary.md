# 用語集

| 用語 | 意味 |
|---|---|
| VAD | Voice Activity Detection。音声区間（人が話している部分）の検出 |
| STT / ASR | Speech-to-Text / 音声認識 |
| TTS | Text-to-Speech / 音声合成 |
| ウェイクワード | エージェントを呼び出すキーワード（例: 「ねえ〇〇」） |
| HFP | Hands-Free Profile。BT の通話用プロファイル。マイク入力が可能だが音質は低め |
| A2DP | BT の高音質音楽再生プロファイル。マイク入力は不可 |
| LE Audio | BT 低消費電力オーディオ規格。LC3 コーデック、双方向音声の改善が期待される |
| ツール (tool use) | LLM が呼び出す外部機能（検索、ToDo 操作など） |
| ADR | Architecture Decision Record。設計判断の記録 |
