# ビジョン

## 一言で
**「耳元にいる、気の利く秘書」** — 画面を見なくても、聞いて・考えて・動いてくれるエージェント。

## 解決したい課題（仮説）
- 会話や移動中に「あとで調べよう」「やらなきゃ」と思ったことを忘れる
- スマホを取り出して操作するのが手間・危険（歩行中、手がふさがっている等）
- 既存の音声アシスタントは「呼ばれたら単発で答える」だけで、文脈を持たない

## 想定ユースケース（ドラフト）
| # | シーン | 入力 | エージェントの動き | 出力 |
|---|---|---|---|---|
| U1 | 会議・雑談中 | 周囲の会話 | 「来週までに資料送る」等を検出 → ToDo 候補化 | 後で一覧で確認 / 控えめな通知 |
| U2 | ふと疑問 | 自分の声「〇〇って何だっけ」 | Web 検索 → 要約 | イヤホンで短く読み上げ |
| U3 | 外出・移動 | 「〇〇駅まで歩きで」 | 経路検索 → ターンバイターン案内 | 曲がり角で音声案内 |
| U4 | 買い物メモ | 「牛乳切れてた」 | 買い物リストに追加 | 「追加しました」 |
| U5 | 振り返り | 「今日のまとめ」 | 1 日の ToDo・調べたことを要約 | 音声 + 画面 |

## やらないこと（現時点）
- 通話の録音・文字起こしサービス（法的・倫理的リスクが大きい）
- 常時クラウド送信による全文ログ化
- （追記していく）

## 成功の姿（定性）
- 1 日つけっぱなしでも電池が持ち、邪魔にならない
- 「言っただけで ToDo になってた」体験が自然に起きる
