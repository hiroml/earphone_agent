# 要件（ドラフト）

> ステータス: ドラフト。確定した項目には ✅、検討中は 🟡、未着手は ⬜ を付ける。

## 機能要件
### 音声入力
- ⬜ F-01 イヤホンマイクから自分の声を取得できる
- ⬜ F-02 周囲の音（会話）を取得できる（イヤホン or スマホマイク）
- ⬜ F-03 ウェイクワード or ジェスチャ（イヤホンのタップ等）で明示的に呼び出せる
- ⬜ F-04 呼び出しなしでも、ToDo 等の候補を受動的に抽出できる（オプトイン）

### エージェント
- ⬜ F-10 自然言語の依頼を解釈し、適切なツールを選んで実行する
- ⬜ F-11 Web 調査 → 要約して音声で返す
- ⬜ F-12 ToDo の作成・更新・完了・一覧
- ⬜ F-13 経路案内（徒歩 / 公共交通）
- ⬜ F-14 会話文脈の短期記憶（直近の会話を踏まえて応答）
- ⬜ F-15 副作用のある操作の前にユーザー確認

### 出力
- ⬜ F-20 イヤホンへの音声応答（TTS）
- ⬜ F-21 アプリ画面での履歴・ToDo 一覧表示

## 非機能要件
| ID | 項目 | 目標（仮） | 備考 |
|---|---|---|---|
| N-01 | 応答レイテンシ | 発話終了 → 音声応答開始 2 秒以内 | 検索系は「調べます」で先に応答 |
| N-02 | 電池消費 | 待機リスニング 8 時間で 〇〇% 以下 | 要計測 |
| N-03 | プライバシー | 生音声は端末外に保存しない（デフォルト） | ADR で例外管理 |
| N-04 | オフライン | ウェイクワード・VAD はオフラインで動作 | |
| N-05 | 対応言語 | 日本語（英語は後回し） | |
| N-06 | 対応端末 | TBD | |
