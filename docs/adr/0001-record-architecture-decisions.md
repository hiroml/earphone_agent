# ADR-0001: アーキテクチャ決定を ADR で記録する

- ステータス: 承認
- 日付: 2026-11-22

## コンテキスト
構想段階で技術選定の論点が多く（OS、音声取得方式、STT、エージェント実行場所など）、後から「なぜこう決めたか」を追えるようにしたい。Claude Code とのやり取りでも判断根拠を参照できる形で残す必要がある。

## 決定
後戻りしにくい設計判断は `docs/adr/NNNN-<slug>.md` に記録する。テンプレートは `0000-template.md`。Claude Code の `/adr` スキルで作成する。

## 影響
- 決定時に CLAUDE.md の技術スタック表・architecture.md も更新する。
- 覆す場合は新しい ADR を作り、古い ADR のステータスを「置き換え済み」にする。
