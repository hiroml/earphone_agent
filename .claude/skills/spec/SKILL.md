# 機能仕様の作成

1. 対象機能を確認する。曖昧なら、ユーザーに 1〜3 個の質問で確認してから進める。
2. `docs/specs/_template.md` をベースに `docs/specs/<英語kebab-case>.md` を作成する。
3. `docs/requirements.md` から関連する要件 ID（F-xx / N-xx）を紐付ける。対応する要件が無ければ追加を提案する。
4. 特に以下を具体的に書く:
   - **音声 UX**: 発話例と応答例（耳で聞いて分かる短い表現にする）
   - **エッジケース**: 聞き取り失敗、ネットワーク断、騒音、誤検出
   - **プライバシー**: 扱うデータと外部送信の有無
   - **受け入れ条件**: テスト可能な形で
5. 未決事項は仕様内に列挙し、重要なものは `docs/open-questions.md` にも追記する。
