# 技術調査

1. 問いを明確にし、関連する `docs/open-questions.md` の Q 番号があれば確認する。
2. 調査は `tech-researcher` サブエージェントに委譲してよい（広い調査の場合）。狭い問いなら直接調べる。
3. 結果を `docs/research/YYYY-MM-DD-<英語kebab-case>.md` に保存する。構成:
   - 問い
   - 結論（2〜3 行）
   - 詳細・根拠（出典 URL 付き）
   - 比較表（該当する場合）
   - 未確認事項・実機検証が必要なこと
   - 次のアクション（ADR 化 / PoC / 追加調査）
4. `docs/open-questions.md` の該当行に調査メモへのリンクを追記する。
5. ユーザーには結論と次のアクション候補を簡潔に報告する。
